# Chamadas finais da T2: as 5 missões

Cada episódio termina com **uma** missão. Aqui estão, para cada uma: a fala do Roberto, o texto da tela final (em vídeo), o comentário fixado, a linha da descrição e a mensagem de WhatsApp.

## Arquivos de vídeo

| Missão | YouTube (16:9, 20 s) | Shorts/Reels (9:16, 4 s) |
|---|---|---|
| M1 · Gerar WhatsApp | `m1-16x9-20s.mp4` | `m1-9x16-4s.mp4` |
| M2 · Gerar visitas | `m2-16x9-20s.mp4` | `m2-9x16-4s.mp4` |
| M3 · Gerar proposta | `m3-16x9-20s.mp4` | `m3-9x16-4s.mp4` |

| M5 · Captar clientes | `m5-16x9-20s.mp4` | `m5-9x16-4s.mp4` |

Os PNGs de mesmo nome servem como imagem estática. `tela-final.html` + `render.js` geram tudo de novo se algum texto mudar.

**Como usar a versão 16:9 no YouTube:** coloque o MP4 de 20 s no fim do episódio e, no YouTube Studio → *Tela final*, posicione:
- o elemento **Vídeo** (ou Playlist) sobre a moldura "ASSISTA TAMBÉM"
- o elemento **Inscrever-se** sobre o círculo "INSCREVA-SE"

A fala do Roberto (abaixo) pode ser narrada **por cima** dos primeiros segundos da tela final, ou logo antes dela, com o imóvel ao fundo.

> **Rastreio:** cada link de WhatsApp abaixo já abre a conversa com uma mensagem pronta que diz "Vi o Vitrine na Praia". Assim dá para contar no placar quantas conversas vieram do programa. Use o link na descrição, no comentário fixado e na bio.

## M4 · Descobrir o perfil do comprador
**Quando usar:** episódios comparativos, imóveis com vários usos possíveis e para aumentar comentários (o YouTube entrega mais vídeos comentados).

**Fala (≈15 s)**
> "Agora eu quero saber de você: você compraria esse imóvel para morar, para investir ou para passar o verão? Me conta aqui nos comentários. Eu respondo todo mundo. E se quiser conversar direto, o WhatsApp está na descrição."

**Tela final:** SUA OPINIÃO · *Morar, investir ou veranear?* · botão "Comente aqui embaixo 👇"

**Comentário fixado (enquete)**
```
👇 Você compraria este imóvel para:

📈 Investir
☀️ Passar o verão
Responde aqui! Quer conversar direto? https://wa.me/5551984211346?text=Ol%C3%A1%20Roberto%21%20Vi%20o%20Vitrine%20na%20Praia%20e%20quero%20conversar%20sobre%20im%C3%B3veis.
```

**Linha da descrição**
```
👇 Conta nos comentários: morar, investir ou veranear? · WhatsApp: https://wa.me/5551984211346?text=Ol%C3%A1%20Roberto%21%20Vi%20o%20Vitrine%20na%20Praia%20e%20quero%20conversar%20sobre%20im%C3%B3veis.
```
